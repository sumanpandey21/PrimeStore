# 🛒 E-Commerce Platform (In Progress)

An **E-commerce web application** built with **Next.js (frontend)** and **Django REST Framework (backend)** — currently under **active development**.  
This project is part of my learning journey to **sharpen full-stack skills** and build a professional-grade system for both **customers** and **admins**.  

> 🚧 The project is not fully complete yet. Development and feature updates are happening continuously as I refine the design, functionality, and performance.

---

##  Features

### 🛍️ Customer Module
- Browse products with images, descriptions, and pricing  
- Add products to cart & manage quantities  
- Wishlist functionality for favorite items  
- Secure checkout with order creation & payment tracking  
- Track order delivery progress *(in development)*  

### 🧑‍💼 Admin Module
- Manage product catalog (CRUD operations)  
- Handle customer orders and update statuses  
- View analytics for sales and user activity *(in progress)*  
- Cancel or approve orders directly from the dashboard
